# Staged 3.0.0 secret-protection upgrade guide

The seven localized pages in `src/content/<locale>/docs/3.0.0/reference/upgrade-guide.mdx` are **intentionally draft**. They document [hs-sql-agent PR #302](https://github.com/tse-wei-chen/hs-sql-agent/pull/302), a breaking change planned for the product's 3.0.0 version.

**Do not make 3.0.0 the site's current documentation version solely to publish these pages.** The site currently pins the released 2.0.6 product tag. The v3 documentation overlay needs its own complete release-diff audit; this guide covers versioned secret protection only, and the product PR is not yet a published release.

## Publication checklist

1. Merge product PR #302 only after product tests and security review pass; address any subsequent changes to cryptographic/storage semantics in all seven translations.
2. Audit the complete 2.0.6 → 3.0.0 public-surface diff before changing `src/data/productRelease.ts` or `src/data/docsVersions.ts`; pin a verified immutable product commit or final tag.
3. Preserve the 2.0.6 documentation tree as historical content. Build the 3.0.0 overlay with inheritance from 2.0.6 and update other changed public contracts.
4. Remove `draft: true` from the seven 3.0.0 upgrade guides after the full release-diff audit. Then check all seven localized paths and links, type-check/build, content source checks, link integrity and SEO.
5. Until that promotion, no `/docs/3.0.0/` route should be published, and `/docs/` must continue describing 2.0.6.

Sources: [product PR #302](https://github.com/tse-wei-chen/hs-sql-agent/pull/302) and its [breaking-change instructions](https://github.com/tse-wei-chen/hs-sql-agent/blob/security/versioned-secret-protection/docs/secret-protection-upgrade.md).
