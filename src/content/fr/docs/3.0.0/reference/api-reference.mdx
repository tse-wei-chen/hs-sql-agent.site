Développez une opération pour inspecter ses paramètres, les champs du corps de requête et ceux de chaque réponse, y compris les objets imbriqués, les types, les champs obligatoires et Nullable. Ces données proviennent des métadonnées OpenAPI des contrôleurs et DTO.

[Commencer par créer une clé système à système depuis l'Admin UI](/fr/docs/integration/management-api-keys).

> Certains anciens IActionResult ne déclarent pas de modèle de réponse : ils sont explicitement indiqués comme non documentés, sans propriété inventée. Suivi : issue #295. Les API de compte ne sont pas accessibles avec une clé système à système.
