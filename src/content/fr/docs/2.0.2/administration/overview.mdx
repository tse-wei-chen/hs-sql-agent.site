## Parcours opérateur recommandé

<Flow items={["Enregistrer la base", "Émettre une clé MCP", "Définir le périmètre outils/tables", "Enrichir les métadonnées", "Connecter le client", "Observer et auditer"]} />

1. Enregistrez et vérifiez la connexion à la base que l’agent doit exposer.
2. Émettez une clé MCP liée à cette base et n’accordez que les outils/tables nécessaires au client.
3. Ajoutez des métadonnées sémantiques lorsque les noms physiques ne suffisent pas à une découverte fiable par l’agent.
4. Générez la configuration cliente et connectez-vous via l’endpoint Streamable HTTP public `/mcp`.
5. Utilisez les surfaces d’audit et d’exploitation pour observer le runtime et resserrer la politique si nécessaire.

<Callout type="info" title="L’authentification Admin et l’authentification MCP sont distinctes">
Les comptes Admin opèrent le plan de contrôle. Les clients MCP s’authentifient avec des clés MCP. Donner un accès Admin à un utilisateur ne crée pas automatiquement un identifiant MCP, et une clé MCP ne donne pas accès à l’interface Admin.
</Callout>

## Cycle de vie des clés MCP

Lorsqu’une clé est émise, renouvelée ou dupliquée, l’interface peut générer directement une configuration Streamable HTTP pour les formats clients pris en charge. Le secret en clair n’est affiché que dans cette boîte de dialogue de cycle de vie et n’est pas conservé pour affichage ultérieur.

Copiez la configuration générée avant de fermer la boîte de dialogue.

## L’interface intégrée et l’identité intégrée sont facultatives

Un hôte ASP.NET Core peut exposer l’API Admin HsSqlAgent sans servir l’interface Admin empaquetée. Dans le mode d’intégration modulaire, utilisez `UseHsSqlAgentAdminApi()` et laissez l’hôte appeler `MapControllers()` ; ajoutez `UseHsSqlAgentAdminUi()` uniquement si l’interface intégrée est souhaitée.

L’hôte peut aussi utiliser `AddHsSqlAgentHostAuthorization(...)` pour conserver son système existant de connexion et de permissions au lieu d’installer les membres, rôles, JWT, SMTP ou OIDC HsSqlAgent. MCP est choisi et mappé indépendamment avec `AddHsSqlAgentMcp(...)` / `UseHsSqlAgentMcp()`.

Consultez [Intégration ASP.NET Core](/fr/docs/integration/aspnet-core) pour le modèle de composition complet de la version 2.0.2.
