## 2.0.5 → 2.0.6 (proposed)

예정된 2.0.6에서는 기존 `/api` 엔드포인트를 자동으로 관리하기 위한 API 키가 추가됩니다.

## 업그레이드 단계

1. 새 서버 버전을 배포하고 Admin Store 마이그레이션으로 `ManagementApiKeys` 테이블을 만듭니다.
2. 관리 화면에서 연동에 필요한 최소 권한만 가진 API 키를 발급합니다.
3. 한 번만 표시되는 비밀 값을 안전하게 보관하고 `X-API-Key`로 허용된 API를 호출합니다.
4. 키 만료·폐기·교체 시의 처리 방식을 확인합니다.

## 호환성 및 롤백

기존 관리자 로그인 및 MCP 클라이언트 연결 방식은 변경되지 않습니다. 이전 서버 버전에서는 관리 API 키를 검증할 수 없으므로 롤백 전에 연동 사용을 중단하세요.

> 관리 권한은 특정 데이터베이스 ID나 테넌트로 자동 제한되지 않습니다. 신뢰할 수 있는 백엔드에서 키를 관리하고 서비스별 접근 정책은 연동 시스템에서 적용하세요.
