## 2.0.5 → 2.0.6 (proposed)

계획 중인 2.0.6에서는 관리자 인터랙티브 로그인 없이 서버 간 관리 API 호출을 지원합니다. SQL 컴파일러와 MCP 도구 실행 동작은 바뀌지 않습니다.

## Management API Keys

새 버전 배포 및 관리 저장소 마이그레이션 후 Management API Keys 화면에서 최소 권한의 키를 발급하세요. 한 번만 표시되는 키를 안전하게 보관하고 허용된 `/api` 요청에 `X-API-Key`를 사용합니다. 사람 관리자는 계속 JWT를 사용하고 MCP 클라이언트는 별도 MCP 키를 사용합니다.

```http
X-API-Key: hsa_mgmt_<secret>
```

## Migration and compatibility

SQLite 및 PostgreSQL 관리 저장소 마이그레이션으로 `ManagementApiKeys` 테이블이 추가됩니다. 키를 발급하기 전에 마이그레이션을 적용하세요. 기존 관리자 JWT와 MCP 키는 변경되지 않습니다.

기존 관리자 JWT, MCP 키, 5개 기본 MCP 도구, SQL 보안 경계는 그대로입니다. 관리 테이블만 추가됩니다. 이전 버전으로 되돌리기 전에 연동 키를 폐기해야 합니다.

> 관리 권한은 데이터베이스 ID나 SaaS 테넌트를 자동으로 격리하지 않습니다. 키는 신뢰할 수 있는 백엔드에만 제공하세요.
