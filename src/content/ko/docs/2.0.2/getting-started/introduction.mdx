hs-sql-agent는 **정책으로 통제된 SQL 접근**을 제공하는 HTTP MCP 서버입니다. MCP 클라이언트를 PostgreSQL, MySQL, SQL Server, Oracle, SQLite, Firebird에 연결하면서 인증, 접근 정책, SQL 검증, 데이터 변경 승인은 서버에서 관리합니다.

<Callout type="danger" title="LLM을 데이터베이스의 보안 경계로 사용하지 마세요">
AI가 생성한 SQL은 신뢰할 수 없는 입력으로 취급합니다. 모델은 SQL을 제안할 수 있지만, 요청에 권한이 있는지, 의미를 안전하게 지원할 수 있는지, 실제로 실행해도 되는지는 서버가 결정합니다.
</Callout>

## 컴파일러가 만드는 실행 경계

생성된 SQL은 실행 전에 파싱되고 검증됩니다. hs-sql-agent는 문장의 의미를 유지하는 데 필요한 기능을 확인하고, 입력 SQL의 의미, 대상 데이터베이스의 지원 범위, 접근 정책을 모두 통과한 경우에만 해당 데이터베이스용 SQL을 생성합니다.

지원하지 않는 구문이나 의미는 겉보기만 비슷한 다른 SQL로 조용히 바꾸지 않고 명시적으로 거부합니다.

<Callout type="info" title="6개 데이터베이스 지원이 모든 벤더 SQL을 그대로 통과시킨다는 뜻은 아닙니다">
지원 여부는 컴파일러가 안전하게 다룰 수 있는 기능 단위로 결정됩니다. 구문을 내부 표현으로 나타낼 수 있고, 의미를 검증할 수 있으며, 대상 데이터베이스용으로 안전하게 생성할 수 있어야 합니다. 각 데이터베이스가 제공하는 모든 확장 구문을 허용한다고 가정하지 말고 SQL 지원 범위를 확인하세요.
</Callout>
