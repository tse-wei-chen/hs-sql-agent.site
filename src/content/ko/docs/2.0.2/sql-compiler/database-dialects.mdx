hs-sql-agent는 현재 다음 6개 관계형 데이터베이스를 대상으로 합니다.

| 데이터베이스 | 역할 |
| --- | --- |
| PostgreSQL | 입력 및 출력 SQL 방언 |
| MySQL | 입력 및 출력 SQL 방언 |
| SQL Server | 입력 및 출력 SQL 방언 |
| Oracle | 입력 및 출력 SQL 방언 |
| SQLite | 입력 및 출력 SQL 방언 |
| Firebird | 입력 및 출력 SQL 방언 |

## MCP 인터페이스가 하나라고 SQL 방언까지 하나인 것은 아닙니다

MCP 클라이언트가 사용하는 서버 계약은 공통이지만 SQL의 의미는 데이터베이스마다 다릅니다. 컴파일러는 설정된 데이터베이스에서 지원하는 SQL의 의미가 그대로 유지되도록 처리합니다.

이 차이는 연산자, 데이터 형식, CAST, 함수, 식별자, 페이지 처리, NULL 의미, DML 동작 등에 영향을 줍니다.

## 지원 범위는 명확히 제한됩니다

지원 데이터베이스 목록에 제품 이름이 있다고 해서 해당 제품이 제공하는 모든 SQL 구문을 허용하는 것은 아닙니다.

입력 구문을 내부 표현으로 안전하게 나타낼 수 없거나 대상 데이터베이스에서 같은 의미를 보존할 수 있다고 확인할 수 없는 경우, 컴파일러는 페일 클로즈 방식으로 거부합니다. 이 원칙을 유지한 채 지원 기능은 계속 확장할 수 있습니다.

운영 환경에서는 각 데이터베이스 CLI가 받아들이는 SQL이 hs-sql-agent에서도 그대로 실행될 것이라고 가정하지 말고, 컴파일러가 실제로 허용하는 범위를 공식 계약으로 취급하세요.
