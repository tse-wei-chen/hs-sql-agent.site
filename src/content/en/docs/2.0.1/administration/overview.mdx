The Admin Panel is the operational control surface for hs-sql-agent. It is separate from the MCP client experience: operators configure access and runtime policy here, while MCP clients use the governed `/mcp` endpoint.

## Runtime areas

The current Admin UI contains dedicated runtime areas for:

- **Database management** — configure database connections exposed through the agent.
- **MCP keys** — issue and manage client credentials and their runtime scope.
- **Custom tools** — define and publish governed SQL tools.
- **Audit** — inspect recorded execution and security activity.
- **Operability** — inspect operational state and delivery/health-related controls.
- **Security** — manage runtime security policy.

Account and authorization pages are also separate from these runtime areas.

## MCP key lifecycle

When a key is issued, rotated, or duplicated, the UI can generate direct Streamable HTTP configuration for supported client formats. The plaintext secret is shown only in that lifecycle dialog and is not retained for later display.

This is why operators should copy the generated configuration before closing the dialog.

## Embedded UI is optional for library consumers

When hs-sql-agent is embedded in an ASP.NET Core application, `UseHsSqlAgent()` can expose the API/MCP pipeline without serving the Admin UI. Calling `.ServeAdminUi()` enables the packaged UI as well.

See [ASP.NET Core integration](/en/docs/integration/aspnet-core) for the basic host setup.
