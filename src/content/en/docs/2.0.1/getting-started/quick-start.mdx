<Callout type="info" title="Start with Docker unless you already own the host application">
Docker Compose is the shortest path because the repository already contains the service wiring and environment-variable mapping. The NuGet path is intended for teams embedding hs-sql-agent into an existing ASP.NET Core host.
</Callout>

## Docker Compose

<Steps>
  <Step title="Create your environment file" description="Copy the checked-in example so configuration stays explicit and reviewable.">

```bash
cp .env.example .env
```

  </Step>
  <Step title="Replace the signing secrets" description="Set HMAC_KEY and JWT_KEY to different, unique secrets of at least 32 bytes.">
The values in `.env.example` are placeholders. Do not deploy them unchanged.
  </Step>
  <Step title="Start the service" description="Launch the default single-instance stack.">

```bash
docker compose up -d
```

  </Step>
  <Step title="Open the Admin Panel" description="The default application listener is port 8080.">
For a local setup, open `http://localhost:8080` and complete the first administrator setup.
  </Step>
</Steps>

## Issue your first MCP key

<Steps>
  <Step title="Open Runtime → MCP Keys" description="Keys are the MCP identity and authorization boundary." />
  <Step title="Choose the database and tool scope" description="Bind the key to one Database Management entry and expose only the tools the client needs." />
  <Step title="Copy the plaintext key" description="The lifecycle dialog displays the newly issued secret for you to copy; keep it in the client secret store." />
  <Step title="Use the generated client configuration" description="Or send the secret as X-MCP-Server-Key to the Streamable HTTP endpoint." />
</Steps>

The default MCP endpoint is `/mcp`. For clients outside the local machine, set `MCP_PUBLIC_ENDPOINT` to the externally reachable absolute HTTP or HTTPS URL, including `/mcp`.

<Callout type="warning" title="DML requires client Elicitation support">
Do not enable `execute_dml_sql` just because a client can call MCP tools. The client also needs compatible MCP form Elicitation so the human can review and approve the exact mutation impact.
</Callout>
