## 建議的管理流程

<Flow items={["註冊資料庫", "簽發 MCP 金鑰", "設定工具/資料表範圍", "補充語意中繼資料", "連接用戶端", "監看與稽核"]} />

1. 註冊並驗證 Agent 要存取的資料庫連線。
2. 簽發一把綁定該資料庫的 MCP 金鑰，只允許用戶端實際需要的工具與資料表。
3. 當原始結構名稱不足以讓 Agent 穩定理解資料時，再補充語意中繼資料。
4. 產生用戶端設定，透過公開的 Streamable HTTP `/mcp` 端點連線。
5. 使用稽核與運作狀態頁面觀察執行情形，必要時再收緊政策。

<Callout type="info" title="管理介面驗證與 MCP 驗證是兩個獨立邊界">
管理員帳號用來操作管理介面；MCP 用戶端則使用 MCP 金鑰。授予某個使用者管理員權限，不會自動替他建立 MCP 憑證；MCP 金鑰也不能拿來登入管理介面。
</Callout>

## MCP 金鑰生命週期

MCP 金鑰在簽發、輪替或複製時，介面可以產生支援格式的 Streamable HTTP 用戶端設定。明文密鑰只會在該次操作的對話框中顯示一次，之後無法再次查看。

關閉對話框前，請先複製需要的設定與密鑰。

## 內嵌 UI 與內建身分系統皆為選配

ASP.NET Core host 可以只掛載 HsSqlAgent Admin API，而不提供隨套件附帶的管理 UI。模組化整合使用 `UseHsSqlAgentAdminApi()`，並由 host 自行呼叫 `MapControllers()`；只有需要內建管理介面時才加入 `UseHsSqlAgentAdminUi()`。

Host 也可以透過 `AddHsSqlAgentHostAuthorization(...)` 沿用既有的登入與權限系統，不必安裝 HsSqlAgent 內建的成員、角色、JWT、SMTP 或 OIDC。MCP 則可使用 `AddHsSqlAgentMcp(...)` / `UseHsSqlAgentMcp()` 獨立選擇與掛載。

完整的 2.0.2 元件組裝方式請參考 [ASP.NET Core 整合](/zh-hant/docs/integration/aspnet-core)。
