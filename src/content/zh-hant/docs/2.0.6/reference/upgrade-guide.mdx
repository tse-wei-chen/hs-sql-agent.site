## 2.0.5 → 2.0.6

此版本新增**管理 API 金鑰**。外部後端系統可使用明確授權的金鑰，自動呼叫既有 `/api` 管理端點。

## 升級步驟

1. 部署新版伺服器，並執行 Admin Store 的 SQLite／PostgreSQL migration，建立 `ManagementApiKeys` 資料表。
2. 在 **Runtime → Management API Keys** 建立金鑰，設定到期時間及整合服務需要的最小權限。
3. 安全保存只顯示一次的明文金鑰。
4. 呼叫管理 API 時，透過 `X-API-Key` 傳入金鑰。
5. 在正式環境驗證到期、撤銷與輪替流程。

## 相容性與回復舊版

本次新增的是管理 API 認證方式及 Admin Store 資料表。既有管理員登入與 MCP Client 連線流程不需要變更。

若回復舊版，請先讓外部整合服務停止使用管理 API 金鑰，因為舊版無法驗證新憑證。

> 管理 API 金鑰的權限以管理操作為單位，目前沒有特定資料庫 ID 或 SaaS 租戶的自動隔離能力。

詳見 [管理 API 金鑰使用指南](/zh-hant/docs/2.0.6/integration/management-api-keys)。
