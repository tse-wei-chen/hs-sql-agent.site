hs-sql-agent は、**統制された SQL アクセス**を提供する HTTP MCP サーバーです。MCP クライアントから PostgreSQL、MySQL、SQL Server、Oracle、SQLite、Firebird へ接続しつつ、認証、アクセスポリシー、SQL の検証、データ更新の承認はサーバー側で管理します。

<Flow items={["MCP クライアント", "MCP キーの権限範囲", "SQL コンパイラ", "ポリシーと対応能力の検証", "データベース"]} />

<Callout type="danger" title="LLM をデータベースのセキュリティ境界にしない">
AI が生成した SQL は信頼できない入力として扱います。モデルは SQL を提案できますが、その要求を実行してよいか、意味を安全に扱えるか、実行して問題ないかを判断するのはサーバーです。
</Callout>

## コンパイラによる実行境界

生成された SQL は実行前に解析・検証されます。hs-sql-agent は文の意味を保つために必要な機能を確認し、入力側の意味、出力先データベースの対応能力、アクセスポリシーのすべてを満たした場合にだけ、そのデータベース向けの SQL を生成します。

対応していない構文や意味は、見た目だけ似た別の SQL に暗黙変換せず、明示的に拒否します。

<Callout type="info" title="6 種類のデータベース対応は、ベンダー固有 SQL の無制限な通過を意味しません">
対応可否はコンパイラが安全に扱える機能単位で決まります。構文を内部表現として保持でき、意味を検証でき、対象データベース向けに安全に生成できることが必要です。各ベンダーの拡張構文をすべて受け入れる前提ではなく、SQL 対応範囲の資料を確認してください。
</Callout>
