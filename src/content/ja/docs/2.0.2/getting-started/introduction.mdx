hs-sql-agent は、**ガバナンスされた SQL アクセス**を提供する HTTP MCP サーバーです。MCP クライアントを PostgreSQL、MySQL、SQL Server、Oracle、SQLite、Firebird に接続しながら、認証、アクセス方針、SQL 検証、mutation approval をサーバー側に保ちます。

<Flow items={["MCP client", "MCP key scope", "SQL compiler", "Policy & capability checks", "Database"]} />

<Callout type="danger" title="LLM をデータベースのセキュリティ境界にしないでください">
生成された SQL は信頼できない入力です。モデルは SQL を提案できますが、リクエストが認可されているか、意味論がサポートされているか、安全に実行できるかを決定するのはサーバーです。
</Callout>

## Compiler boundary

生成された SQL は実行前に parse と validate が行われます。hs-sql-agent はステートメントの意味を保つために必要な capability を確認し、リクエストが source、target、policy の各 boundary を通過した後にのみ provider-specific SQL を生成します。

サポートされていない syntax や semantics は、見た目だけ似た SQL に暗黙変換されるのではなく拒否されます。

<Callout type="info" title="6つの provider をサポートしていても arbitrary vendor SQL passthrough ではありません">
Provider support は capability-driven です。ある construct を受け入れるには、その意味を表現・検証し、対応する source/target contract に従って安全に render できる必要があります。すべての vendor extension が受け入れられるとは想定せず、SQL support reference を契約として扱ってください。
</Callout>
