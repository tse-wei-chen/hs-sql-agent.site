<Callout type="info" title="ホストアプリケーションを既に所有していない限り、Docker から始めてください">
Docker Compose が最短経路です。リポジトリに service wiring と environment-variable mapping が既に含まれています。NuGet は、既存の ASP.NET Core host に hs-sql-agent を組み込むチーム向けです。
</Callout>

## Docker Compose

<Steps>
  <Step title="environment file を作成" description="checked-in example をコピーし、configuration を明示的かつ review 可能な状態にします。">

```bash
cp .env.example .env
```

  </Step>
  <Step title="signing secret を置き換える" description="HMAC_KEY と JWT_KEY に、それぞれ異なる 32 bytes 以上の unique secret を設定します。">
`.env.example` の値は placeholder です。そのまま deploy しないでください。
  </Step>
  <Step title="サービスを起動" description="標準の single-instance stack を起動します。">

```bash
docker compose up -d
```

  </Step>
  <Step title="Admin Panel を開く" description="標準の application listener は port 8080 です。">
ローカル環境では `http://localhost:8080` を開き、最初の administrator setup を完了します。
  </Step>
</Steps>

## 最初の MCP key を発行

<Steps>
  <Step title="Runtime → MCP Keys を開く" description="Key は MCP identity と authorization boundary です。" />
  <Step title="database と tool scope を選ぶ" description="Key を 1 つの Database Management entry に結び付け、client が必要とする tool だけを公開します。" />
  <Step title="plaintext key をコピー" description="lifecycle dialog に新しく発行された secret が表示されます。client secret store に保存してください。" />
  <Step title="生成された client configuration を使う" description="または Streamable HTTP endpoint に X-MCP-Server-Key として secret を送信します。" />
</Steps>

標準の MCP endpoint は `/mcp` です。ローカルマシン外の client から接続する場合は、`MCP_PUBLIC_ENDPOINT` に `/mcp` を含む外部到達可能な absolute HTTP/HTTPS URL を設定します。

<Callout type="warning" title="DML には client 側の Elicitation support が必要です">
MCP tool を呼び出せるだけで `execute_dml_sql` を有効にしないでください。人が正確な mutation impact を確認して承認するには、client が互換性のある MCP form Elicitation を実装している必要があります。
</Callout>
