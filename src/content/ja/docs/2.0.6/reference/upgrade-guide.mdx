## 2.0.5 → 2.0.6 (proposed)

予定されている 2.0.6 では、既存の `/api` エンドポイントをプログラムから操作するための API キーを追加します。

## アップグレード手順

1. 新しいサーバーをデプロイし、Admin Store のマイグレーションで `ManagementApiKeys` テーブルを作成します。
2. 管理画面で連携に必要な権限だけを付与した API キーを発行します。
3. 一度だけ表示される秘密値を安全に保管し、認可された API への呼び出しに `X-API-Key` を使います。
4. 有効期限切れ・失効・ローテーション時の動作を確認します。

## 互換性とロールバック

既存の管理者ログインと MCP クライアントの接続方法は変更されません。旧バージョンでは管理 API キーを検証できないため、ロールバック前に連携での使用を停止してください。

> 管理権限は特定のデータベース ID やテナントに自動では限定されません。信頼できるバックエンドにキーを保管し、アプリケーション固有の認可は連携側で実装してください。
