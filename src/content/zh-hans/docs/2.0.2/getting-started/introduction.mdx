hs-sql-agent 是一个为**受控 SQL 访问**设计的 HTTP MCP 服务器。它让 MCP 客户端连接 PostgreSQL、MySQL、SQL Server、Oracle、SQLite 和 Firebird，同时把身份验证、访问策略、SQL 验证以及数据修改审批都保留在服务器端。

<Flow items={["MCP 客户端", "MCP 密钥权限范围", "SQL 编译器", "策略与功能支持检查", "数据库"]} />

<Callout type="danger" title="不要让 LLM 成为数据库的安全边界">
AI 生成的 SQL 应视为不可信输入。模型可以提出 SQL，但请求是否有权限、语义是否受支持、是否可以安全执行，都由服务器决定。
</Callout>

## 编译器形成的执行边界

AI 生成的 SQL 会在执行前经过解析和验证。hs-sql-agent 会检查保持语句原有含义所需的能力，只有输入语义、目标数据库支持范围和访问策略全部满足要求时，才会生成对应数据库的 SQL。

不支持的语法或语义会被明确拒绝，而不是静默改写成一个看似相近但含义可能不同的 SQL。

<Callout type="info" title="支持六种数据库，并不等于任意厂商 SQL 都能直接透传">
支持范围按编译器能够安全处理的功能逐项确定。一个语法结构必须能被内部表示、验证，并能为目标数据库安全生成等价 SQL，才算真正受支持。不要假设数据库自身接受的所有扩展语法都会被 hs-sql-agent 接受，应以 SQL 支持范围文档为准。
</Callout>
