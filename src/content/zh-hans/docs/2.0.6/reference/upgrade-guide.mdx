## 2.0.5 → 2.0.6 (proposed)

计划中的 2.0.6 版本增加 API 密钥认证，让外部系统直接调用现有的 `/api` 管理接口。

## 升级步骤

1. 部署新版服务器，执行 Admin Store 迁移，创建 `ManagementApiKeys` 表。
2. 在管理界面创建密钥，只选择集成服务需要的权限。
3. 安全保存只显示一次的明文，并使用 `X-API-Key` 请求头调用接口。
4. 验证密钥过期、撤销与轮换的处理流程。

## 兼容性与回滚

现有管理员登录和 MCP 客户端连接流程无需更改。旧版服务器无法验证管理 API 密钥；回滚前请先停止在集成中使用这些密钥。

> 管理权限目前不会按数据库 ID 或租户自动限制。请将密钥保存在可信任的后端，并由集成服务自行执行应用层授权。
